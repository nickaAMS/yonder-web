For iPhone and iPad

Apple

Apple shares preview apps through TestFlight. If this is your first test, install it first.

  1. Install TestFlight from the App Store if you do not already have it.
  2. Open the Namesake invitation, then choose Install in TestFlight.
Open TestFlight invitation →

You may be asked to sign in with your Apple ID.

For Android

Android

Download the latest Namesake preview directly to the Android device you will use.

  1. Download Namesake using the button below.
  2. Allow the download when Android asks for permission.
  3. Open the downloaded file and choose Install.
